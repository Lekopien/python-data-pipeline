Data engineering · Python

From messy CSV to clean insight

A dependency-free Python ETL pipeline: it streams a dirty sales export, validates and cleans every row, loads SQLite idempotently and renders a report with hand-drawn SVG charts.

View sourceRun it locally

Highlights

Real-world cleaning

Three date formats, region typos, KES and USD prices with separators, duplicates, blanks.

Nothing silently dropped

Every rejected row is written to rejected.csv with the reason.

Exact money

Decimal arithmetic end to end; no floating-point drift in totals.

Idempotent load

INSERT OR REPLACE keyed by order id, so reruns never duplicate data.

Charts without libraries

SVG line and bar charts generated in pure Python.

Automated

CI runs tests, executes the pipeline and publishes the report as an artifact.
